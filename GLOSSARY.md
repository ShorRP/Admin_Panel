# Shor Admin Panel

The tooling Shor's staff use to run the community around Shor, a Skyrim roleplay server.

## Language

### Places

**Shor**:
The Skyrim multiplayer (SkyMP) roleplay server this project serves.
_Avoid_: ShorRP (the GitHub organization's name), the game

**Discord server**:
The Discord community space around Shor, where no roleplay is played.
_Avoid_: guild, the Discord, server (alone)

### People

**Staff**:
The members of Shor's team who moderate and administer the community.
_Avoid_: admins, mods (each names a level within the staff, not the staff as a whole)

**Staff role**:
A Discord role that makes a member of the Discord server part of the staff.
_Avoid_: admin role, mod role

### Tools

**Admin Panel**:
The web application the staff use to administer the Discord server without code or bot commands.
_Avoid_: dashboard, painel, staff panel

**Bot**:
The Discord bot loanspac runs, which reacts to what happens on the Discord server. Not the Admin Panel's own Discord application, which acts only when a staff member uses the panel.
_Avoid_: ShorBot (the repository's name), client, panel bot

**Audit log**:
The Admin Panel's record of which staff member changed what, and when. Not the panel's logs, which say only why the panel failed.
_Avoid_: logs, moderation log

### Moderation

**Whitelist**:
The approval that gives a player access to roleplay on Shor, granted by the staff after reviewing their application.
_Avoid_: allowlist

**Blocked word**:
A word or phrase the staff forbid in messages on the Discord server. Not the opposite of the whitelist.
_Avoid_: blacklist, banned word, forbidden word

**Panel's rule**:
The AutoMod rule on the Discord server whose keywords are the blocked words, which the Admin Panel creates and keeps. Not the AutoMod rules the staff make in Discord, which the panel only shows.
_Avoid_: blocked words rule, the rule (alone)

**Warning**:
A formal notice from the staff to a member of the Discord server, with its reason, kept on record even when the member contests it successfully.
_Avoid_: strike
